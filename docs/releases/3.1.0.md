# GEstimator 3.1.0

GEstimator 3.1 adds estimation skill libraries for MCP clients and improves
keyboard editing, category paste and project file access on Flatpak.

## What's new

- **Estimation skills.** Choose Generic or the India (IN) skillset for civil and
  electrical takeoff. The IN library also covers preliminary lighting. A
  shared rate-analysis guide is available with every library. Add office guides
  through the MCP tab and refresh them while the server is running.
- **Keyboard navigation.** Move from database search into results with the
  arrow keys, select a range with Shift and add with Enter. The Analysis
  explorer and measurement link picker also support keyboard navigation.
  Focus stays with the editor after common insert, paste and edit actions.
- **Categories and schedule layout.** Copy categories and their contents in
  Schedule, Resources and Measurements. Paste categories as separate groups
  and paste ordinary rows into the selected category. Long schedule
  descriptions wrap more reliably.
- **Database imports.** When two selected items depend on one another, both
  are imported and the dependent analysis keeps its prefixed reference.
  GEstimator keeps SUB ANALYSIS last in the schedule, resources and Excel export.
- **Flatpak.** Choose projects and external libraries through the desktop file
  chooser. Save with a writable grant or choose the project folder when
  prompted. Clipboard actions support copying rows between app windows.

See the [user manual](../manual/README.md) for the workflows and keyboard shortcuts.

## Upgrade and install

Open existing `.eproj` projects in 3.1. On Windows, uninstall any 2.x
installation under **Settings → Apps** before installing 3.x.

Get the Windows installer, Linux `.deb` or AppImage, standalone Flatpak,
or Snap from [GitHub Releases](https://github.com/manuvarkey/GEstimator/releases).
Check the version listed on [Flathub](https://flathub.org/apps/com.kavilgroup.gestimator)
or the [Snap Store](https://snapcraft.io/gestimator) before installing there.
