## Notes

- NBCS 2026 gives the lumen method and the definitions, but no numeric maintenance factor; the skill takes it from IS 3646 (Part 1).
- NBCS 2026 Table 6 values differ from NBC 2016 (as reproduced in the CPWD specification) for some rooms, for example teaching spaces and washrooms. Name the code used in each handoff.
- Typical floor reflectance and the example luminaire data are stated assumptions.

## Codes adopted

The skill uses NBCS 2026 (criteria and method) and ECSBC 2024 (lighting power and controls), the current codes. IS 3646 (Part 1):1992 supplies only the maintenance factor, which NBCS 2026 does not give. ECSBC 2024, 7.2.1, refers lighting quantity and quality to the latest IS 3646 (Part 1); BIS has a revision in preparation.
