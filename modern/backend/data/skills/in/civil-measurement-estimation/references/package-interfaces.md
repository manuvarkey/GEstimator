# Reconcile package boundaries

Record interface ID, drawing revision, physical quantity, item inclusions, responsible package and separately payable quantity. Split components where one contractor supplies and another installs. Keep unassigned scopes visible. Reconcile both parties' schedules before pricing.

| Interface | Physical scope | Payable allocation in this example |
|---|---|---|
| R1, rated floor | Two service penetrations | Builder forms two openings within its slab item. Fire package provides two tested seal assemblies matched to the service and opening. |
| P1, pump plinth | 1.8 × 0.9 × 0.3 m concrete | Civil measures 0.486 m³. Pump vendor includes anchors and grout in its set. |
| E1, common earth ring | 108 m including 30 m shared side | Electrical owns 108 m. Lightning package references the shared side and books only its additional bonds. |
| X1, surfaced crossing | 5 × 0.8 m reinstatement | Road package books 4 m² where the electrical trench rate excludes reinstatement. |
| C1, first chamber | Building drain, chamber and outlet | Plumbing ends at chamber inlet. Site drainage owns chamber and downstream reach. |

Apply the same check to cable shafts/fire stops, waterproof roof penetrations, sleeves, tank walls, pump power/control cabling, authority connections and integrated commissioning. If a composite includes a component, keep its physical count for coordination with zero additional payable quantity. For a change, trace every affected package by interface ID.
