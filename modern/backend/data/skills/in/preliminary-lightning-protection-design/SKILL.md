# Preliminary lightning protection design

For each building, record the adopted standard edition, occupancy, site exposure, roof plans/elevations, incoming services, soil data and whether the brief or authority mandates protection. CEA 2023 regulation 38(3)(vi) refers covered buildings to the relevant lightning standards. Establish the protection class from the applicable risk assessment or documented project requirement.

- If the need or class is open, use [risk and design basis](gestimator://skills/in/preliminary-lightning-protection-design/references/risk-basis.md).
- With a confirmed or explicitly assumed class, use [layout and quantities](gestimator://skills/in/preliminary-lightning-protection-design/references/layout.md). Carry an assumed class as a priced alternative for review.
- For an issued design, measure its actual routes and components, then use [electrical takeoff](gestimator://skills/in/electrical-measurement-estimation) for schedule matching and reviewed writes.

Return the class and its basis, a roof/earth layout keyed to the drawing, equipment and conductor quantities, surge protection interfaces, testing provisions and unresolved checks.
