# External electrical estimation

Start with the site plan, single-line diagram, cable and duct schedules, profiles, crossing permissions, utility boundary and responsibility for reinstatement. Use [preliminary-lv-distribution-design](gestimator://skills/in/preliminary-lv-distribution-design) for LV feeder sizing. Take higher-voltage assets from the utility or issued design. Return route lengths by installation method and equipment counts by asset ID. Read [the measurement and schedule-matching workflow](gestimator://skills/in/electrical-measurement-estimation) for source notes, item matching, measurement templates and applying reviewed quantities. Keep unmatched quantities in the draft. Use the [shared rate-analysis skill](gestimator://skills/shared/rate-analysis) for a requested non-schedule analysis.
