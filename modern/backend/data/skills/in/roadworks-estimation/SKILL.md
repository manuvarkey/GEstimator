# Roadworks estimation

Start with the authority, schedule edition, chainage datum, surveyed ground, formation levels and adopted typical sections. Split at changes in geometry, layer specification, material and payment unit. Return chainage, section revision, layer, dimensions, unit and inclusion basis for each item. Read [the measurement and schedule-matching workflow](gestimator://skills/in/civil-measurement-estimation) for source notes, item matching, measurement templates and applying reviewed quantities. Keep unmatched quantities in the draft. Use the [shared rate-analysis skill](gestimator://skills/shared/rate-analysis) for a requested non-schedule analysis.
