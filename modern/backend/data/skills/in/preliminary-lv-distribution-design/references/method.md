# Preliminary LV distribution design — method

Group loads by board and phase. Separate input kW, shaft output kW and kVA. Convert shaft output using equipment efficiency. Use documented coincidence or demand factors at the level where they apply. For single phase use I = input W / (V × PF). For balanced three phase use I = input W / (√3 × line V × PF). For unbalanced boards check each phase and neutral duty.

Select cable material, insulation, cores and reference installation method. Correct the applicable tabulated capacity for the actual ambient, grouping and burial conditions. Compare design current, protective device setting, corrected capacity and device operating current under IS 732 clause 4.4.4.1. Include starting duty, downstream and upstream drop, prospective short-circuit current, device breaking capacity, conductor withstand and disconnection. Record residual protection and bonding for the supply arrangement.

For a manufacturer voltage-drop coefficient in mV/A/m for the stated circuit arrangement, drop in volts = coefficient × current × one-way metres / 1000. Check whether the coefficient includes the return or three-phase factor. Compare the cumulative drop to the adopted limit at the load. Preserve known route quantities if device curves, source impedance or earth test data are missing.
