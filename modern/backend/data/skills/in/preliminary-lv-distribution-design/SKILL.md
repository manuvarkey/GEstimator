# Preliminary LV distribution design

For a preliminary circuit or feeder, read [the feeder selection card](gestimator://skills/in/preliminary-lv-distribution-design/references/feeder-selection.md) once for all runs using its conditions. It includes candidate ratings, correction factors, voltage drop and the measurement handoff. Return the governing check and any unresolved inputs for each circuit. For an issued cable schedule go straight to [electrical takeoff](gestimator://skills/in/electrical-measurement-estimation).
